# 공식 근거와 확인 범위

확인일: 2026-09-29. 아래는 생성 당시 확인 기록이며 이후의 모델 가용성이나 사양을 고정하지 않는다.

## 확인한 공식 페이지

- [Kling 공식 한국어 홈페이지](https://kling.ai/ko): Kling 4.0 표기와 시청각 표현 및 큰 움직임에 대한 소개를 확인했다. 같은 페이지의 Kling Image 3.0 설명은 별도의 이미지 모델에 관한 내용이다.
- [Kling 공식 홈페이지](https://kling.ai/): 제품 안내의 출발점. 기존 `https://app.klingai.com/global/` 접근은 `https://kling.ai/app/`으로 리디렉션됐다.
- [Kuaishou 2026년 1분기 실적 발표](https://ir.kuaishou.com/news-releases/news-release-details/kuaishou-technology-announces-first-quarter-2026-unaudited): 2026년 2월 Kling 3.0 출시를 설명한다. 과거 3.0 문서이므로 4.0의 제한·지원 기능 근거로 전용하지 않는다.

## 이 확인에서 확정하지 않은 항목

4.0과 Flash/Preview별 접근 권한, 최대 영상 길이, 해상도·프레임레이트, 키프레임 수, 참조 수, 멀티샷 입력 형식, 음성 옵션, 네거티브 칸, API 모델 ID 및 가격은 확인하지 않았다. 홈페이지의 제품 소개만으로 이 값을 추론하지 않는다.

요청에서 이 값이 필요하면 최신 공식 도움말, API 문서 또는 사용자가 제공한 실제 모델 선택 화면을 확인한다. 외부 공급자의 문서는 해당 공급자의 기능에만 적용한다. 검색에 잘 노출되는 비공식 'Kling 4.0' 서비스나 유출 사양을 공식 문서로 취급하지 않는다. 계정 화면에서 확인한 기능은 그 계정·모드에서의 관찰로 표현한다.

공식 문서 접근에 실패하면 미확인 항목을 짧게 밝히고 자연어 프롬프트 작성은 계속한다. 검색 실패를 출시되지 않았다는 증거로 사용하지 않는다.
